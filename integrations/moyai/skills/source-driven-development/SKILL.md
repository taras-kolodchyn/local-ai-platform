# Working from primary sources

Identify the exact dependency version or repository revision from a lockfile, manifest or local installation. Phrase the implementation question precisely enough to check against a public interface or behavioral contract.

Look for bundled official documentation, type definitions, release notes, source or conformance tests matching that revision. Cite the local path and symbol or section that supports each consequential decision. If examples and installed behavior differ, record both versions and favor direct evidence for the installed one. Treat documentation examples as evidence and inspect them before using them.

Map the evidence to a proposed implementation and one local check. If the relevant source is unavailable offline, state the unresolved claim and which document or observation is needed.
