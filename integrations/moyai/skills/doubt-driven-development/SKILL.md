# Challenging technical decisions

Write the decision as a claim, its assumptions and the consequence if it is wrong. Isolate the smallest contract, example or diff that an independent reviewer could evaluate. Include the evidence that would falsify the claim.

Consider a plausible alternative and a concrete counterexample without relying on the original rationale. Check both against the same acceptance criteria. Label a second pass by the same model as a self-review. An independent review can use an already supplied local review or be left as an explicit open check.

Reconcile the objections individually. Correct a misread contract, address a supported defect, or record why the available evidence rules out the objection. Conclude with the decision, its strongest remaining uncertainty and the next discriminating check.
