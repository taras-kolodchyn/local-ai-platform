# Refining an idea

Restate the problem around a particular user, situation and desired outcome. Surface the assumption most likely to make the idea irrelevant. When an answer would materially change the direction, ask a focused question using the user's own terms.

Generate a few distinct options by changing the audience, delivery channel or simplest intervention. Compare the options on usefulness, feasibility, effort to learn and reversibility. Identify evidence that would cause each option to be abandoned.

Return a short concept brief with the selected direction, assumptions, the smallest useful scope, what is deferred and one experiment with a measurable outcome. Draft it in chat unless the task explicitly calls for a file and writing is available.
