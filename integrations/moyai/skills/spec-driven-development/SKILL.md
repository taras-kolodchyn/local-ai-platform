# Specification before implementation

Define the actor, objective, success condition and constraints. Capture a representative input and output, failure behavior and one edge case. Trace affected interfaces, data compatibility and dependencies in the local project.

Draft a compact specification with scope, explicit exclusions, acceptance criteria and a mapping from each criterion to an observable check. Separate requirements from changeable design choices. Identify ambiguities that would lead to different behavior and record decisions with their rationale.

When revising a specification, describe current behavior, proposed behavior and the migration path for existing callers. Keep the specification and its checks aligned when scope changes. Present the draft for review when the task is to define requirements.
