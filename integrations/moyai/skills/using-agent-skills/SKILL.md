# Choosing a workflow

Use this workflow when asked to discover, explain or choose among available workflows. Match the requested deliverable against the descriptions actually offered in the current local catalog. Identify the smallest set that covers the work. A routine factual question may need none.

For several deliverables, map each one to a distinct contribution and identify any dependency between them. Explain overlaps so that closely related skills do not create duplicate work. A loaded skill contributes local guidance within the current profile's tool permissions.

Return the selection and a brief reason for each choice. Use instructions already returned in this turn. Avoid recursively selecting this guide or asking the user to name skills to make an ordinary request work.
